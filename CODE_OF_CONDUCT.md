# Code of Conduct

Viskod is a technical project built through respectful collaboration. This policy applies to issues, pull requests, discussions, reviews, and project channels.

## Expected behavior

- Be respectful, specific, and constructive.
- Assume good intent while addressing impact directly.
- Welcome different backgrounds, experience levels, and viewpoints.
- Focus technical disagreement on evidence, tradeoffs, and user outcomes.
- Protect private application data, credentials, and security reports.

## Unacceptable behavior

Harassment, discrimination, intimidation, threats, personal attacks, sexualized conduct, doxxing, deliberate disruption, and sharing another person's private information without consent are not acceptable. Repeatedly ignoring project boundaries or maintainer instructions is also unacceptable.

## Enforcement

Maintainers may edit, hide, close, or remove content and may restrict participation when behavior violates this policy. Decisions prioritize safety, consistency, and the health of the project.

Report conduct concerns privately to a repository maintainer through GitHub rather than escalating them in a public thread. Security vulnerabilities must use the private process in [`SECURITY.md`](SECURITY.md).
