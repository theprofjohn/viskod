# Purpose

This roadmap defines the long-term evolution of Viskod.

Its purpose is to communicate strategic direction rather than implementation schedules.

The roadmap explains **where** the platform is heading.

It does not commit to **when** features will be delivered.

---

# Vision

Viskod aims to become the world's leading **Visual Context Platform** for AI-assisted software engineering.

Its mission is to provide AI coding agents with reliable visual understanding, project awareness and deterministic context, enabling them to make better engineering decisions with less hallucination and greater confidence.

---

# Strategic Principles

The roadmap is guided by the following principles:

* Browser is the source of truth.
* Repository is the source of truth.
* Local-first by default.
* MCP-first integrations.
* Evidence before inference.
* Deterministic over probabilistic.
* Platform before product.
* Extensibility over customisation.

These principles should remain stable across future releases.

---

# Roadmap Structure

The roadmap is organised into successive capability phases rather than calendar dates.

Each phase builds upon the guarantees established by previous phases.

---

# Phase 1 — Foundation

Objective:

Establish the core Visual Context Platform.

Primary deliverables include:

* Browser Runtime
* Visual Context Engine
* Project Scanner
* Source Hint Engine
* Context Packet generation
* Studio
* SDK
* CLI
* Plugin System
* MCP integration
* Deterministic architecture

Success criteria:

* Stable platform architecture
* Public SDK
* Public Plugin API
* Reliable Context Packet generation
* Cross-platform desktop support

# Platform Evolution

Across every phase, the platform should continue improving:

* performance
* scalability
* accessibility
* security
* privacy
* reliability
* documentation
* developer experience

No roadmap phase should weaken previously established architectural guarantees.

---

# Out of Scope

The roadmap intentionally excludes:

* becoming a code editor
* replacing existing IDEs
* becoming a general-purpose AI agent
* proprietary lock-in
* platform-specific implementations

Viskod remains a Visual Context Platform.

---

# Success Metrics

Long-term platform success may be measured through:

* Context Packet quality
* AI task success rate
* developer adoption
* plugin ecosystem growth
* SDK adoption
* platform stability
* enterprise adoption
* community contributions

Metrics should guide prioritisation rather than dictate architecture.

# Roadmap North Star

The Viskod roadmap exists to guide the platform toward becoming the world's most trusted Visual Context Platform for AI-assisted software engineering.

Its responsibility is to provide a clear strategic direction while preserving the architectural principles that make Viskod deterministic, extensible and evidence-driven, ensuring every future capability strengthens the platform rather than redefining it.
